## 📋 文件职责

### 1. server.py - 主服务器
**职责**：定义 MCP 工具，处理业务逻辑

**功能**：
- ✅ 定义 4 个 MCP 工具
- ✅ 管理论文缓存
- ✅ 调用 Semantic Scholar API
- ✅ 使用限流器保证安全

**依赖**：
- `rate_limiter.py` - 限流器
- `mcp` - MCP 框架
- `requests` - HTTP 请求

---

### 2. rate_limiter.py - 文件队列限流器
**职责**：确保跨进程安全，精确限流

**功能**：
- ✅ 文件锁机制（跨进程安全）
- ✅ 时间队列管理（精确限流）
- ✅ 自动清理过期请求
- ✅ 死锁检测和恢复

**依赖**：
- 无外部依赖，仅使用标准库

---

### 3. request_queue.json - 队列数据
**职责**：存储请求队列

**格式**：
```json
[
  {
    "id": "req_12345_67890",
    "scheduled_time": 1234567890.123,
    "created_at": 1234567889.123,
    "status": "pending",
    "pid": 12345
  }
]
```

**字段说明**：
- `id`: 唯一标识（格式：`req_{进程ID}_{时间戳}`）
- `scheduled_time`: 调度执行时间（Unix 时间戳，秒）
- `created_at`: 创建时间（Unix 时间戳，秒）
- `status`: 状态（pending/completed）
- `pid`: 创建进程的ID

---

### 4. request_queue.lock - 锁文件
**职责**：防止并发冲突

**格式**：
```json
{
  "pid": 12345,
  "timestamp": 1234567890.123,
  "hostname": "DESKTOP-ABC"
}
```

**字段说明**：
- `pid`: 持有锁的进程ID
- `timestamp`: 获取锁的时间（Unix 时间戳，秒）
- `hostname`: 主机名

**生命周期**：
1. 获取锁时创建
2. 操作完成后删除
3. 超时30秒自动清理

---

### 5. .bibtex.json - 论文缓存
**职责**：缓存已搜索的论文

**格式**：
```json
{
  "Vaswani2017AttentionIA": {
    "title": "Attention Is All You Need",
    "bibtex": "@Article{...}",
    "abstract": "...",
    ...
  }
}
```

## 🔄 数据流程

### 搜索论文流程

```
1. 用户发起搜索请求
   ↓
2. server.py 调用 rate_limiter.wait_for_turn()
   ↓
3. rate_limiter 执行：
   ├─ 获取文件锁
   ├─ 读取队列文件
   ├─ 计算下次执行时间
   ├─ 写入队列文件
   ├─ 释放文件锁
   └─ 等待到指定时间
   ↓
4. 执行 API 请求
   ↓
5. 缓存结果到 .bibtex.json
   ↓
6. 从队列删除请求
   ↓
7. 返回结果给用户
```

## 🔐 安全机制

### 问题1：死锁
**场景**：进程崩溃，锁未释放

**解决**：
- 锁文件包含时间戳
- 超过30秒自动清理
- 所有操作有超时保护

### 问题2：并发冲突
**场景**：多进程同时操作队列

**解决**：
- 文件锁保护整个读写过程
- 原子操作 `O_CREAT | O_EXCL`
- 原子写入（临时文件+重命名）

### 问题3：时间错误
**场景**：系统时间调整、请求堆积

**解决**：
- `max()` 防止时间倒流
- 自动清理超过60秒的过期请求

### 问题4：文件损坏
**场景**：写入时崩溃

**解决**：
- 原子写入（先写临时文件，再重命名）
- 异常处理自动重建

### 问题5：竞态条件
**场景**：多进程同时检测过期锁

**解决**：
- 全面的异常处理
- FileNotFoundError 静默忽略

### 问题6：进程崩溃
**场景**：请求写入队列后崩溃

**解决**：
- 每次读取时清理过期请求
- 请求ID包含进程ID和时间戳，确保唯一

## ⚙️ 配置参数

### rate_limiter.py

```python
FileQueueRateLimiter(
    queue_file="request_queue.json",  # 队列文件路径
    min_interval=1.0                   # 最小请求间隔（秒）
)
```

**参数说明**：
- `queue_file`: 队列文件路径（相对或绝对路径）
- `min_interval`: 最小请求间隔，默认1.0秒

## 📝 使用示例

```python
# 1. 创建限流器
limiter = FileQueueRateLimiter("queue.json", min_interval=1.0)

# 2. 等待轮次
request_id = limiter.wait_for_turn()

# 3. 执行请求
response = requests.get("API...")

# 4. 完成请求
limiter.done(request_id)

# 5. 查看状态
status = limiter.get_queue_status()
```
